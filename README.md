# MyOrbit

나만의 속도로, 나만의 궤도를.

MyOrbit은 일상 속 일정, 목표, 할 일, 컨디션 등을 기록하고 관리할 수 있는 개인 맞춤형 자기관리 웹 서비스입니다.

해야 할 일에 쫓기기보다 자신의 생활 패턴과 속도에 맞춰 하루를 관리하고, 꾸준한 기록을 통해 스스로의 성장을 확인할 수 있도록 만드는 것을 목표로 합니다.

## 1. 프로젝트 소개

- 프로젝트명: MyOrbit
- 프로젝트 형태: 개인 자기관리 웹 서비스
- 개발 목적: 일정 및 할 일 관리, 목표 설정, 컨디션 기록을 통한 자기관리
- 개발 기간: 진행 중

## 2. 주요 기능

### 1) 홈 (Dashboard)
- 오늘의 할 일 확인 및 관리
- 이번 주 핵심 목표 3가지 확인
- 오늘의 컨디션 확인
- 습관 실천 여부 기록
- 주요 메뉴 및 기능 바로가기
- 알림 및 개인 프로필 확인

### 2) 달력 (Calendar)
- 날짜별 일정 등록 및 관리
- 일정 완료 여부 체크
- 일정 완료 통계 확인
- 월별 일정 확인
- 생리 주기 및 관련 정보 표시 (추후 구현 예정)

※ 달력은 약속, 수업, 외출 등 날짜 중심의 일정을 관리하는 기능입니다. 오늘의 할 일과는 별도로 관리합니다.

### 3) 목표 관리 (Goal Management)
- 만다라트 목표 설정 및 관리
- 연간 및 월간 목표 설정
- 주간 목표 설정
- 목표별 진행 상황 확인
- 목표 달성률 관리

### 4) 오늘의 할 일 (Todo)
- 할 일 등록 및 삭제
- 할 일 완료 여부 체크
- 중요도에 따른 우선순위 설정
- 오늘의 할 일 진행 상황 확인
- 완료한 할 일과 남은 할 일 구분

※ Todo는 수행해야 할 작업을 관리하는 기능으로, 달력의 일정과 연동하지 않고 독립적으로 관리합니다.

### 5) 마음과 몸 (Mind & Body)
- 오늘의 기분 기록
- 신체 및 심리적 컨디션 기록
- 복용 약물 기록
- 약 복용 후 증상 및 변화 기록
- 컨디션과 생활 패턴 기록
- 생리 주기 및 PMS 관련 기록 (추후 구현 예정)

### 6) 나의 성장 (My Growth)
- 주간 성장 리포트
- 목표 달성 현황 확인
- 할 일 완료 통계
- 습관 실천 현황 확인
- 컨디션 및 기분 변화 확인
- 기록을 바탕으로 생활 패턴 분석
- AI를 활용한 개인 맞춤형 성장 분석 (추후 구현 예정)

### 7) 설정 (Settings)
- 사용자 정보 관리
- 개인 설정 관리
- 서비스 이용 환경 설정

### 8) 고객센터 (Customer Center)
- 서비스 이용 안내
- 자주 묻는 질문
- 문의 및 건의사항

## 3. 개발 환경 및 기술 스택

- Language: Java
- Frontend: HTML, CSS, JavaScript, jQuery
- Backend: JSP
- Database: 추후 결정
- IDE: Eclipse
- Server: Apache Tomcat 10.1
- Version Control: Git, GitHub

## 4. 프로젝트 개발 방향

처음에는 기본적인 화면 구성과 기능 구현을 중심으로 개발하고, 이후 데이터베이스를 연결하여 실제 사용자 데이터를 저장하고 관리할 수 있도록 확장할 예정입니다.

또한 단순히 할 일을 관리하는 서비스에서 나아가 목표 달성 과정과 일상 기록을 바탕으로 자신의 생활 패턴을 파악하고 성장할 수 있는 서비스를 만드는 것을 목표로 합니다.
