# MyOrbit 🌱

## 1. 프로젝트 소개

MyOrbit은 목표와 할 일을 관리하고, 매일의 기분과 증상을 기록할 수 있는 웹 서비스입니다.

장기적인 목표를 작은 행동으로 나누어 실천할 수 있도록 돕고, 계획한 일을 완료하지 못하더라도 상황에 맞게 다시 계획할 수 있도록 하는 것을 목표로 합니다. 또한 일상에서 느끼는 기분과 증상을 기록하면서 자신의 상태와 생활 패턴을 돌아볼 수 있습니다.

## 2. 주요 기능

### 목표 관리

- 월간 목표를 만다라트 형태로 작성하고 관리
- 목표를 구체적인 할 일로 나누어 관리
- 목표별 진행 상황 확인

### 할 일 관리

- 주간 및 일간 할 일 등록, 수정, 삭제
- 할 일 완료 여부 관리
- 완료하지 못한 할 일 재계획

### 기분 및 증상 기록

- 일일 기분 기록
- 여러 증상 선택 및 증상 없음 선택
- 추가 메모 작성
- 날짜별 기록 조회 및 수정

### 향후 추가 기능

- 집중 시간 및 활동 기록
- 주간 및 월간 통계
- 생활 패턴 분석
- AI 기반 목표 설정 및 맞춤형 피드백

## 3. 기술 스택
